# PressHarden 0.1.0

WordPress hardening and policy management.

## Initial independent release

WordPress locking/unlocking, configuration policies, automatic-update preferences, authentication/cache-salt rotation, and conservative PHP inspection/configuration now have their own standalone tool. No PressWarden installation is required.

Configuration changes use private backups, staged validation, target checks and readback/rollback safeguards. PHP settings written on disk are not claimed to be web-effective without runtime verification. Salt validation supports both current and legacy WP-CLI JSON field names without exposing raw values.

## Primary commands

```bash
pressharden lock-status example.com
pressharden wp-settings example.com
pressharden auto-updates status example.com
pressharden lock example.com
```

This release does not enable automatic updates or harden any website merely by being published or installed. Review the selected target, intended configuration and recovery instructions before changing production sites.

## Verification and downloads

This release is published only after all required main-branch workflows pass for the exact source commit. `SOURCE.json` records the commit, Git tree and passing workflow-run links. `SHA256SUMS` covers the tracked-source archive, source manifest and these notes. No local work files, credentials or client data are included.

The initial split included isolated WordPress/MySQL integration, PHP 7.4 compatibility, fixture/lifecycle tests and downloaded-installer regressions. Consult the recorded CI evidence for the released commit rather than assuming all hosting environments were tested.

Publication does not install anything on client servers or modify websites, databases or scheduled tasks. Effective web PHP settings, actual HTTP cache/CDN behavior, credentialed external services and a database restore/recovery drill remain staging checks. A checksum-verified backup is not a tested restore.

See `docs/MIGRATION.md`, `docs/RELEASING.md` and `PROVENANCE.md` in the source archive.
