# PressHarden 0.1.3

A manual cleanup command for old PressHarden recovery copies.

## Everyday use

- `backups prune --older-than=DAYS [--apply]` removes old recovery copies. It
  previews by default. Only `COMPLETED` wp-config transactions and successful
  `php-policy` backups are eligible. The newest copy per site and category is
  kept. Apply must match the previewed set exactly, and removals are logged.
  It works on PressHarden's own private state only, so `--target` is refused.

## Update

From an installed PressHarden directory, run:

```bash
./pressharden update
./pressharden version
./pressharden config-new
```

Use `PRESSHARDEN_REF=v0.1.3 ./pressharden update` to select this release
explicitly. Private configuration and state are preserved. There are no data
migrations or new sibling dependencies. Source publication does not change any
website configuration.
